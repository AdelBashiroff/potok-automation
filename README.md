# Поток — автоматизация рутины для малого бизнеса

Демо-лендинг для услуги по настройке автоматизаций. Главное на странице — рабочая демка: тестовая заявка из формы проходит цепочку «таблица → Telegram менеджеру → автоответ клиенту», а кнопка «Взять в работу» в сообщении меняет статус в таблице. Чистые HTML, CSS и JavaScript, без зависимостей и сборки.

## Что внутри

- демо-цепочка из четырёх шагов с проверкой полей и защитой от повторного запуска
- калькулятор экономии: время на рутину, стоимость часа, срок окупаемости пакета
- блоки: что автоматизируем, как работаем, цены, вопросы
- адаптив и `prefers-reduced-motion`, данные пользователя выводятся через `textContent`

В демо ничего не отправляется: всё происходит в браузере.

## Запуск

Открыть `index.html` или `python3 -m http.server`.
